# Reglas operativas del proyecto

1. El trabajo utiliza un único agente principal.
2. No se crean subagentes salvo autorización expresa de Marcelo Chávez.
3. El entorno local autorizado es Conda `msp_01`.
4. No se implementa Docker en esta fase.
5. No se modifica producción ni se ejecutan publicaciones o despliegues reales durante la implementación inicial.
6. Las credenciales permanecen fuera del repositorio y de los logs.
7. Los scripts operativos deben funcionar sin llamadas a modelos de lenguaje.

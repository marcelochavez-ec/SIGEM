# Django development

Aplicar este skill cuando se modifiquen modelos, formularios, vistas, URLs, templates, estáticos o permisos Django.

1. Revisar primero la estructura y la funcionalidad existente.
2. Reutilizar modelos, servicios y componentes antes de crear nuevos.
3. Mantener separadas UI, lógica Python, CSS y JavaScript.
4. Considerar migraciones antes de modificar modelos.
5. Ejecutar `manage.py check` y las pruebas aplicables mediante Conda `msp_01`.
6. Documentar el módulo en español técnico y en tercera persona.

# Software quality

Aplicar este skill después de cambios relevantes.

1. Usar únicamente herramientas disponibles en `msp_01`, sin instalar dependencias automáticamente.
2. Ejecutar sintaxis, `manage.py check` y pruebas existentes cuando estén disponibles.
3. Revisar secretos, imports, rutas y archivos generados.
4. Registrar comando, fecha, resultado y limitaciones.
5. No declarar una prueba aprobada si no fue ejecutada.

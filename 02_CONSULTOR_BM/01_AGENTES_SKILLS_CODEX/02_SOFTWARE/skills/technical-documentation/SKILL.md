# Technical documentation

Aplicar este skill cuando se cree o modifique documentación del sistema.

1. Escribir en español técnico claro, tercera persona y con tildes.
2. Identificar objetivo, archivos, flujo, entradas, salidas, datos, reglas, dependencias, validaciones y riesgos.
3. Mantener fuentes `.qmd` y generar PDF/DOCX solo cuando Quarto y Pandoc estén disponibles.
4. Marcar como pendiente todo dato no comprobado.
5. No publicar credenciales, datos personales ni aprobaciones no verificadas.

# Technical manuals with Quarto

Aplicar este skill para generar o revisar los manuales institucionales.

1. Mantener los `.qmd` en `04_DOCUMENTACION`.
2. Derivar inventarios desde archivos verificables mediante Python.
3. Renderizar PDF y DOCX con `quarto render` dentro de `msp_01`.
4. Registrar dependencias faltantes y no afirmar formatos no validados.
5. Mantener redacción objetiva, tercera persona y sin credenciales.
6. Utiliza para el formato estandarizado y no cambies el formato, los outputs siempre serán: word y PDF de los directorios 01_MANUALES y 02_INFORME_TECNICO

# Agentes para software

Ámbito para agentes que definen reglas de desarrollo del aplicativo SIGES: arquitectura Django, separación de capas, frontend, estilos, documentación, validación, despliegue y mantenimiento.

## Componentes actuales

1. `AGENTES_SIGES_SOFTWARE.md`: agente principal del aplicativo SIGES. Define reglas de trabajo para el desarrollo del software, incluyendo diseño institucional, organización por capas, documentación, validación y criterios de mantenimiento.

# 03_IA

Carpeta local para centralizar agentes, skills, configuraciones y recursos de asistencia técnica utilizados en el proyecto SIGES.

Esta carpeta permanece fuera del repositorio Git y no debe sincronizarse con GitHub. Su finalidad es conservar reglas operativas reutilizables para futuros cambios sin mezclar estos recursos con las estructuras de base de datos ni con el código fuente del aplicativo.

## Organización

1. `01_ESTRUCTURAS_BD`: recursos relacionados con estructuración, procesamiento, validación y gestión de bases de datos.
2. `02_SOFTWARE`: recursos relacionados con desarrollo, mantenimiento, validación y despliegue del aplicativo.

## Uso

Antes de iniciar un cambio, revisar el agente o skill correspondiente al ámbito de trabajo. Los recursos de esta carpeta orientan la forma de trabajar, pero no forman parte del aplicativo entregable ni deben publicarse.
